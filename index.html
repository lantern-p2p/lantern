    A clear privacy picture

    Your files aren't a cloud upload.

    Here is what Lantern's current public beta does—and doesn't—handle.

    ↔

    What Lantern's server does

    It introduces the two devices using a temporary room code and forwards the small WebRTC setup messages needed to connect.

    ⌁

    What it does not receive

    File contents travel through the encrypted peer-to-peer data channel when a direct path is available; the signaling server does not store the files.

    ⏱

    Keep both devices open

    Transfers happen live between your devices. Leave both pages or the desktop app open and connected until the recipient has saved the files. Large transfers can use substantial memory.

    Beta limitations: the service may sleep or restart, which clears temporary rooms. Google STUN may observe public IP addresses, and some networks block direct WebRTC connections because Lantern currently has no TURN relay. The service has not had an independent security audit. Avoid sensitive files for now.
    Good to know

    A few quick answers.

    Do I need to create an account?

    No. The beta is designed for a quick, one-time transfer. You only need the room code from the person you're connecting with.

    Can Lantern see or keep my files?

    The signaling server is not sent file bytes. A direct connection is encrypted by WebRTC. Both devices must stay open until the transfer completes.

    Why might a connection fail?

    Some firewalls and restrictive networks prevent direct peer connections. If that happens, try another network; this beta has no relay fallback yet.
